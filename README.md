# Warung Kanza & Zafran

Game keluarga untuk anak 6–10 tahun: masak di warung, baca menu, hitung uang, tebak huruf/kata/angka, tangkap bahan, dan kartu kembar. Ada 50 level per game, stiker, dan kartu gosok hadiah.

Mainkan: buka halaman GitHub Pages repositori ini di browser HP.
